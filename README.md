## About this module

This project is now focused on Google Play API observability.

PIB-OSS runs as an LSPosed/Xposed module in the Play Store process and logs Integrity service request/response activity per target app. It is designed for debugging and telemetry workflows, and supports optional response rewriting for controlled testing scenarios.
